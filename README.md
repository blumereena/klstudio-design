# klstudio.design

Статическая версия сайта студии дизайна интерьера KL STUDIO. Размещается на
GitHub Pages, домен задан в `CNAME`.

## Структура

```
index.html          главная страница
privacy/index.html  политика обработки персональных данных
404.html            страница ошибки
assets/js/          собственные скрипты (обработчик формы)
wp-content/         изображения и скрипты темы
CNAME               привязка домена klstudio.design
.nojekyll           отключает обработку Jekyll'ом на GitHub Pages
```

## Форма обратной связи

Отправку обрабатывает `assets/js/contact-form.js`. Приёмник задаётся двумя
константами в начале файла:

```js
var FEEDBACK_HOST = '';
var FEEDBACK_PATH = '/api/feedback';
```

`FEEDBACK_HOST` — схема и домен сервиса, принимающего заявки (без слеша на
конце; лишний всё равно отрежется), `FEEDBACK_PATH` — путь до эндпоинта.
Разметку и стили при смене приёмника менять не нужно.

Пока `FEEDBACK_HOST` пустой, скрипт проверяет обязательные поля и показывает
сообщение об успехе, не обращаясь к сети, — форма на живом сайте не отдаёт
ошибку, если приёмник ещё не поднят. Как только константа заполнена, уходит
`POST` с JSON:

| поле | содержимое |
|---|---|
| `name` | имя |
| `email` | почта |
| `phone` | телефон |
| `message` | площадь объекта и пожелания, необязательное |
| `consent` | `true`, без согласия отправка не начинается |
| `page` | адрес страницы, с которой ушла заявка |
| `elapsed_ms` | сколько миллисекунд заполняли форму |

Успехом считается любой ответ `2xx`. Таймаут — 10 секунд. Любой другой код,
сетевая ошибка или таймаут показывают сообщение с телефоном и почтой, кнопка
при этом разблокируется для повторной попытки.

Что нужно на стороне приёмника:

- `Access-Control-Allow-Origin: https://klstudio.design`;
- обработка preflight-запроса `OPTIONS` — его вызывает
  `Content-Type: application/json`;
- `Access-Control-Allow-Headers: Content-Type` и
  `Access-Control-Allow-Methods: POST, OPTIONS`.

Запрос идёт с `credentials: 'omit'`, cookies и заголовки авторизации не
передаются. Значение `FEEDBACK_HOST` попадает в отдаваемый браузеру файл, то
есть эндпоинт публичный по определению — защиту от мусора нужно держать на
стороне приёмника. С сайта в этом помогают два поля: скрытая ловушка
`feedback-trap` (если бот её заполнил, запрос не уходит вовсе) и
`elapsed_ms` — у автозаполнения оно неправдоподобно маленькое.

Кнопка «Отправить» заблокирована, пока не отмечено согласие на обработку
персональных данных, и блокируется снова после успешной отправки — форма
очищается вместе с галочкой.

При любой правке `contact-form.js` поднимайте номер версии в `?v=` у тега
`<script>` в `index.html`, иначе вернувшиеся посетители получат старую версию
из кэша.

## Локальный запуск

```sh
python3 -m http.server 8000
```

Затем открыть <http://localhost:8000/>.

Открывать `index.html` напрямую через `file://` не стоит — относительные пути
к скриптам в этом режиме работают не так, как на сервере.

## Деплой

Push в ветку по умолчанию. В настройках репозитория:
**Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка
`/ (root)`.
